# Security Policy

Please report suspected vulnerabilities privately to the repository maintainers using GitHub's private vulnerability reporting feature, if enabled. Avoid opening public issues containing exploit details before a fix is available.

OpenVPS Toolkit is intended to collect diagnostics without changing system state. It does not upload reports. Reports can contain sensitive host and network metadata; inspect them before sharing.

Do not run unreviewed scripts as root. The optional installer operates in the current user's home directory and does not require root.
